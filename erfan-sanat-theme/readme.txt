پوسته سازمانی و فروشگاهی شرکت دانش‌بنیان عرفان صنعت اصفهان (نورپردازی شهری و المان‌های نوری).

== Description ==
پوسته اختصاصی، پرسرعت، ایمن و بومی وردپرس برای شرکت دانش‌بنیان عرفان صنعت اصفهان با پشتیبانی کامل از ووکامرس، پروژه‌های نورپردازی شهری، مقالات فنی، پنل تنظیمات اسکیما-محور و طراحی راست‌به‌چپ (RTL).

ویژگی‌های کلیدی:
* طراحی کاملاً بومی بدون وابستگی به صفحه‌سازها (Elementor, Divi, WPBakery) یا فریم‌ورک‌های خارجی
* ذخیره‌سازی یکپارچه تنظیمات پوسته در یک ردیف دیتابیس (`erfan_sanat_options`) با کش استاتیک در هر درخواست (`es_opt()`)
* پشتیبانی کامل از ووکامرس و سه حالت سفارش کالا: خرید آنلاین (`online_cart`)، استعلام تلفنی (`phone_inquiry`) و مناقصه رسمی (`official_tender`)
* پست‌تایپ سفارشی پروژه‌های نورپردازی شهری (`project`) به همراه طبقه‌بندی نوع پروژه (`project_cat`) و موقعیت جغرافیایی (`project_location`)
* متاباکس‌های مهندسی برای محصولات، پروژه‌ها و مقالات فنی به همراه اسکیما FAQPage
* دارایی‌های محلی (فونت وزیرمتن WOFF2، آیکون‌های SVG و تصاویر بهینه) بدون هیچ‌گونه درخواست به CDN خارجی

== Installation ==
1. فایل فشرده `erfan-sanat-theme.zip` را از مسیر «نمایش > پوسته‌ها > افزودن پوسته تازه» بارگذاری و نصب نمایید.
2. پوسته «Erfan Sanat Enterprise WordPress Theme» را فعال کنید.
3. از منوی «تنظیمات عرفان صنعت» در پیشخوان وردپرس، تنظیمات برندینگ، رنگ‌ها، صفحه اصلی و ابزارهای داده نمونه را مدیریت نمایید.
